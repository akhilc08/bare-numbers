# Bare Numbers Between Agents

Code, data and results for the L4 project: when a personal agent delegates a request to another organisation's agent, the number arrives intact but its unit doesn't. Built on [CAPRI](https://arxiv.org/abs/2606.17688) (Miao, Zhu & Shwartz 2026).

- `L4-conventions/` — the project. Start with [`L4-conventions/README.md`](L4-conventions/README.md).
- `_lib/` — the small stdlib-only helpers the run scripts import (Claude CLI, Codex CLI, OpenRouter clients).

The account email and institution that the subscription CLI injected into some agent transcripts are redacted as `[operator-email]`, `[operator-id]` and `[operator-institution]`. The related-paper PDFs are not included; `L4-conventions/papers/README.md` lists them with arXiv links. CAPRI's own files keep their license (`L4-conventions/capri/LICENSE_capri.md`).
